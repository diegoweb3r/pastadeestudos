# 🧑‍💻 Como funciona a Internet?
<p align="justify">
A internet é a espinha dorsal da web, a infraestrutura técnica que faz a web possível. A internet começou em contexto de guerra, tornando-se infraestrutura pública nos anos 80. Quando dois computadores precisam se comunicar, você precisa conecta-los, seja fisicamente ou sem fio. Uma rede não é limitada a dois computadores, podemos conectar quantos computadores necessário, porém, é complexo quando o número de computadores aumenta. Para resolver, cada computador na rede esta conectado a um aparelho chamado roteador. Esse roteador tem o trabalho de sinalizar, como uma estação de trem, ter certeza que a mensagem enviada por um determinado computador chegue ao destinatário corretamente. Com esse aparelho, antes, conectar 10 computadores dependeria de muitos cabos para conectar todos, mas agora, os vários PCs sao direcionados a um roteador que administra todos os acessos.

## Rede de redes
<p align="justify">
Podemos conectar muitos PCs a um roteador, mas no contexto de milhares, fica inviável, mas, conseguimos conectar um roteador (com vários PCs) a outros roteadores. Juntando vários roteadores é formar uma rede parecida com a internet mas nao a torna viável para conectar a outras redes fora de casa. Por isso, utiliza-se de infraestruturas já existentes, como a de cabos de telefonia e para isso utilizamos um outro aparelho chamado modem (os modernos ja funcionam como roteador). Depois de conectado, para enviarmos mensagens para a rede é preciso um provedor de serviço de internet, conhecido com ISP em inglês. São as ISP que gerenciam roteadores especiais que são conectados e podem acessar roteadores de outros ISPs. E a internet é composta por toda essa infraestrutura de redes. 

## Encontrando computadores
<p align="justify">
Se voce quer enviar uma mensagem par aum computador, você precisa especificar qual é o computador. Por isso, qualquer computador conectado a internet possui um único endereço de identificação chamado de IP (Internet Protocol). Formado por uma série de 4 números separados por pontos. Essa solução funciona para computadores mas fica mais difícil para seres humanos, por isso, existem apelidos para IPs, chamamos de domínio, como exemplo: google.com é o apelido para o endereço de IP 142.250.190.78.

## A internet e a web
<p align="justify">
A internet é a infraestrutura técnica que permite conectar bilhões de computadores. Entre esses computadores, alguns são os servidores que podem enviar mensagens inteligíveis. Então a web é um serviço construído sob essa infra estrutura.
</p>

## Intranet e Extranets
<p align="justify">
Intranets são redes privadas restritas a membros de uma organização particular. São usadas para prover portal para que os membros tenham acesso a recursos compartilhados e comunicação de forma segura.
</p>
<p align="justify">
Já Extranets são semelhantes, mas são abertas, normalmente usadas para compartilhar informações de forma segura para interessados. Ambos os serviços funcionam na infraestrutura da internet e usam os mesmos protocolos.
</p>
