# 🧑‍💻 Como funciona a Web?
<p align="justify">
Como a Web funciona oferece visão simplificada do que acontece quando você vê uma página em um navegador.
</p>


## Clientes e servidores
<p align="justify">
Computadores conectados a Web são chamados de clientes e servidores.
<ul>
<li> Clientes são os dispositivos dos usuários da web e programas de acesso à Web disponíveis nesse dispositivo.
<li> Servidores são computadores que armazenam páginas, sites ou aplicativos. Quando o dispositivo do cliente acessar uma página, uma cópia dela é baixada do servidor pra máquina do cliente.
</p>

## Outras partes da caixa de ferramentas
<p align="justify">
O cliente e o servidor não são o todo, existem outras questões quando se fala de Web. Além de cliente e servidor precisamos de:
<ul>
<li> Conexão com internet: permite o acesso aos dados da Web
<li> TCP/IP: Protocolo de transmissão e Protocolo de Internet, são os protocolos de comunicação que definem como os dados trafegam na web.
<li> DNS: Servidor de nome de domínio são o catálogo de endereço de sites. Ele busca o domínio e localiza o real endereço.
<li> HTTP: Protocolo de transferência de HyperTexto é um protocolo que define uma linguagem para clientes e servidores
</p>
